Подключение Яндекса

Яндекс Трекер, Почта, Диск, Календарь и другие сервисы Яндекса через MCP.

Перед началом

MCP-сервер — это «мост» между AI-приложением и сервисом. Настройки ниже подойдут для Codex, Claude, Cursor и другого клиента, если в выбранном сервере есть поля для токена или OAuth.

Важно

Яндекс Трекер

Для API нужен OAuth-токен и идентификатор организации. Сам Трекер предоставляет API; MCP-сервер вы выбираете или запускаете отдельно.

5 шагов
1

Создать OAuth-приложение

Откройте Яндекс ID OAuth, нажмите Создать, затем выберите Для доступа к API или отладки → Перейти к созданию.

В открывшемся окне отметьте Для доступа к API или отладки и нажмите Перейти к созданию.

2

Выбрать права

Укажите название, например MCP Яндекс, и контактный email. В поле доступа добавьте только сервисы, которые должен видеть MCP:

  • tracker:read — только чтение задач, очередей и пользователей;
  • tracker:write — создание и изменение задач. Берите его, только если AI должен что-то менять.
  • Почта — доступ на чтение писем; доступ на отправку и изменение писем добавляйте, только если он действительно нужен.
  • Яндекс Диск — чтение файлов; запись добавляйте, только если AI должен загружать, перемещать или менять файлы.
  • Календарь — чтение событий; запись добавляйте, только если AI должен создавать или менять встречи.
  • Метрика, Директ и другие сервисы — ищите название сервиса в поле доступа и выбирайте минимальный уровень прав, который требует конкретный MCP-сервер.

Названия и доступность прав зависят от подключённого сервиса. Не добавляйте почту, Диск или Календарь «на всякий случай». Затем нажмите Создать приложение.

3

Получить OAuth-токен

Откройте созданное приложение и скопируйте ClientID. Подставьте его в ссылку, откройте её в браузере и войдите именно в тот аккаунт, от имени которого AI будет работать с задачами:

https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID

На следующей странице появится OAuth-токен. Он понадобится при настройке MCP на следующем шаге.

4

Узнать ID организации

В Яндекс Трекере откройте Администрирование → Организации и скопируйте значение поля «Идентификатор».

5

Заполнить секреты MCP и проверить доступ

Названия полей могут немного отличаться у конкретного MCP-сервера. Обычно ему нужны такие значения:

YANDEX_TRACKER_TOKEN=ваш_OAuth_токен YANDEX_TRACKER_ORG_ID=ID_организации YANDEX_TRACKER_ORG_HEADER=X-Org-ID

Проверка без MCP: в PowerShell подставьте реальные значения локально. Ответ с профилем означает, что доступ работает.

curl.exe -X GET "https://api.tracker.yandex.net/v3/myself" ^ -H "Authorization: OAuth ВАШ_ТОКЕН" ^ -H "X-Org-ID: ID_ОРГАНИЗАЦИИ"

Официально: доступ к API Яндекс Трекера и формат запросов и заголовки.

Подключение Google

Google Drive, Gmail и Google Calendar через готовый коннектор или собственный MCP с OAuth.

Google Workspace

Для Google Drive, Gmail и Calendar сначала проверьте, есть ли в AI-клиенте готовый коннектор. Только для стороннего MCP-сервера с собственным OAuth нужен Google Cloud.

6 шагов
1

Если есть готовый коннектор — используйте его

В настройках AI-приложения найдите Google Drive, Gmail или Google Calendar, нажмите «Подключить» и подтвердите доступ в Google. В этом варианте не нужно создавать OAuth-клиент, получать токен вручную или передавать пароль.

2

Включить нужные API

В Google Cloud Console откройте APIs & Services → Library, найдите нужный API и нажмите Enable. Для Gmail и Calendar повторите то же самое, если они нужны вашему MCP.

3

Настроить экран согласия OAuth

В Branding заполните имя приложения и email поддержки, затем сохраните. В Audience оставьте External и добавьте себя в Test users. В Data access выберите только scopes из документации MCP-сервера.

4

Создать OAuth-клиент

Откройте Clients → Create client. Тип приложения и Redirect URI возьмите из документации выбранного MCP-сервера, затем нажмите Create.

5

Подключить MCP и проверить

Передайте Client ID и Client secret в настройки MCP-сервера. При первом запуске он откроет страницу Google: войдите в нужный аккаунт и подтвердите запрошенные права.

6

Типичные проблемы

Access blocked — добавьте себя в Test users или попросите администратора Google Workspace разрешить приложение. Ошибка redirect URI — сверяйте URI с инструкцией MCP-сервера символ в символ. После перехода приложения в Production Google может потребовать верификацию для чувствительных прав.

Официально: OAuth для desktop-приложений, настройка OAuth consent screen и политики OAuth.

Telegram + GPT

Как подключить Telegram к AI и настроить ежедневную сводку по продажам ОСАГО в нужный чат, группу или канал.

Подключить Telegram

Нужны номер Telegram, код подтверждения и данные приложения с my.telegram.org.

8 шагов
1

Открыть my.telegram.org

Перейдите на my.telegram.org и введите номер в международном формате: с кодом страны и без пробелов.

2

Если появляется ERROR

Если появляется ошибка, отредактируйте файл hosts и временно выключите VPN. Сайт должен открываться через строку из hosts, а не через VPN-маршрут.

3

Отредактировать файл hosts

Откройте папку C:\Windows\System32\drivers\etc, найдите файл hosts и выберите редактирование в Блокноте. Если Windows не даёт сохранить изменения, откройте свойства файла или папки и временно разрешите изменение.

4

Добавить рабочие строки

В hosts пишется не ваш IP-адрес, а IP сервера Telegram и домен, который должен открываться через него. Итоговый вариант для my.telegram.org:

149.154.167.220 my.telegram.org

После сохранения откройте PowerShell и очистите DNS-кэш, чтобы Windows сразу увидела новое правило:

ipconfig /flushdns

Эта строка нужна как временный обход ошибки с доменом. Для создания нового API-ключа VPN должен быть выключен: если на роутере есть DNS-маршрут для Telegram, временно отключите это правило или исключите my.telegram.org из маршрутизации через VPN. После создания Telegram-приложения строку лучше убрать из hosts, потому что IP у сервиса может измениться.

Если способ не сработал, проверьте DNS на устройстве и на роутере. Для этой проверки DNS не должен быть принудительно задан через Google DNS, DoH или DoT: временно используйте DNS провайдера или обычный системный DNS.

5

Открыть инкогнито

Откройте новое окно браузера в режиме инкогнито и снова перейдите на my.telegram.org. Это помогает избежать старых cookies и кэша после ошибки.

6

Ввести код из Telegram

Код придёт в Telegram от служебного аккаунта. Введите его на сайте. Никому не пересылайте этот код: он подтверждает вход в управление приложениями Telegram.

7

Создать приложение

Откройте раздел API development tools и заполните форму. Пример на английском:

App title: PersonalClientApp Short name: personalclient26 URL: пустое Platform: Desktop Description: Personal client application for working with Telegram data.
8

Сохранить api_id и api_hash

После создания Telegram покажет api_id и api_hash. Сохраните их в безопасном месте и передавайте только тому AI-клиенту или скрипту, которому доверяете. После этого верните VPN и DNS как было, а временную строку 149.154.167.220 my.telegram.org удалите из hosts.

Создать утреннюю сводку

Правило каждый день собирает продажи ОСАГО по партнёрам, сравнивает с предыдущим днём и отправляет сообщение в Telegram.

6 шагов
1

Создать ежедневное правило

В AI-клиенте откройте автоматизации или расписание задач и создайте новое ежедневное правило на утро.

2

Указать источник продаж

Дайте AI доступ к источнику, где есть продажи ОСАГО: базе, таблице или отчёту. Важно, чтобы там были партнёр, дата продажи и признак успешной оплаты.

3

Описать расчёт

Попросите брать продажи за вчера и сравнивать их с днём до этого: количество продаж, динамику по каждому партнёру и общий итог.

4

Настроить отправку в Telegram

Укажите, куда отправлять результат: личный чат, группу или канал. Для группы и канала заранее добавьте туда аккаунт или бота, через который выполняется отправка.

5

Вставить промпт

Можно использовать такой текст и заменить @тутчат на нужный чат, группу или канал:

Подготовь утреннюю сводку по продажам по продукту ОСАГО и отправь результат в Telegram чат @тутчат. Используй завершенный предыдущий день как отчетный период и сравни его с днем до него. Формат сообщения: 🚗 ОСАГО | утро {дата} 🏁 Всего продаж: {N} 📊 К предыдущему дню: {+/-N} ({+/-X}%) Партнеры: 🟢 {Партнер 1} — {N} / {+/-N} к вчера 🟢 {Партнер 2} — {N} / {+/-N} к вчера 🔴 {Партнер 3} — {N} / {+/-N} к вчера ⚪ {Партнер 4} — {N} / без изменений 💡 Главное: {короткий вывод одной строкой} Используй тематические эмодзи. Будь кратким и телеграмным. Не отправляй дубли, если сводка за тот же отчетный день уже была отправлена этим процессом.
6

Запустить тест

Сначала выполните правило вручную и проверьте, что сообщение ушло в правильное место, числа похожи на реальный отчёт, а динамика считается от предыдущего дня.

Готовые промпты для отчетов

Эти тексты можно вставлять в расписание задач и менять только чат, продукт, период или источник данных.

6 промптов
1

Продажи и выручка за день

Подходит для ежедневного контроля общего результата, количества продаж и суммы премии.

Подготовь ежедневную сводку по продажам ОСАГО и отправь результат в Telegram чат @тутчат. Используй завершенный предыдущий день как отчетный период и сравни его с днем до него. Покажи: 🚗 количество оплаченных продаж; 💰 сумму премии ОСАГО без допродаж; 📊 динамику к предыдущему дню в штуках и процентах; 🏆 топ-5 партнеров по продажам; 💡 главный вывод одной строкой. Формат сделай коротким, телеграмным и со смайликами по теме. Не отправляй дубли, если отчет за этот день уже был отправлен этим процессом.
2

Просадки партнеров

Помогает быстро увидеть, у кого вчера стало меньше продаж и где нужен разбор.

Каждое утро подготовь отчет по партнерам ОСАГО с падением продаж и отправь результат в Telegram чат @тутчат. Сравни завершенный предыдущий день с днем до него. Покажи только партнеров, у которых продажи снизились. Формат: 📉 ОСАГО | просадки {дата} 🔴 {Партнер} — {N} продаж / {−N} к вчера ({−X}%) 🔴 {Партнер} — {N} продаж / {−N} к вчера ({−X}%) 💡 Главное: {у кого самая заметная просадка и насколько она влияет на общий итог} Если просадок нет, напиши коротко: «Просадок по партнерам нет, день прошел ровно». Не отправляй дубли за один и тот же отчетный день.
3

Неоплаченные заявки

Полезно для контроля брошенных оформлений и точек, где можно дожимать продажи.

Подготовь утренний отчет по неоплаченным заявкам ОСАГО и отправь результат в Telegram чат @тутчат. Возьми заявки за завершенный предыдущий день и сравни с днем до него. Покажи: 🧾 всего заявок ОСАГО; ✅ оплачено; ⏳ не оплачено; 📊 долю неоплаченных; 🔎 топ-5 партнеров по количеству неоплаченных заявок; 💡 короткий вывод, где самый большой резерв. Пиши кратко, в стиле Telegram. Используй тематические эмодзи. Не отправляй дубль, если отчет за этот день уже был отправлен этим процессом.
4

Лидеры роста

Хороший позитивный отчет: показывает, кто дал прирост и за счет кого вырос общий день.

Подготовь отчет «Лидеры роста ОСАГО» и отправь результат в Telegram чат @тутчат. Сравни продажи за завершенный предыдущий день с днем до него. Покажи партнеров, у которых был рост продаж. Формат: 🚀 ОСАГО | лидеры роста {дата} 🟢 {Партнер} — {N} продаж / +{N} к вчера (+{X}%) 🟢 {Партнер} — {N} продаж / +{N} к вчера (+{X}%) 🏁 Всего прирост: +{N} продаж 💡 Главное: {кто внес самый большой вклад в рост} Если роста нет, напиши коротко и без воды. Не отправляй дубли за один и тот же день.
5

Допродажи и кроссы

Отдельный контроль мини-КАСКО, НС и других допродаж рядом с ОСАГО.

Подготовь ежедневный отчет по допродажам к ОСАГО и отправь результат в Telegram чат @тутчат. Используй завершенный предыдущий день и сравни его с днем до него. Покажи: 🎁 количество ОСАГО с допродажей; 💰 сумму допродаж; 📊 долю продаж ОСАГО с допродажей; 🏆 топ партнеров по допродажам; 🔴 партнеров, у которых допродажи просели; 💡 главный вывод одной строкой. Формат короткий, телеграмный, со смайликами. Не отправляй дубли за тот же отчетный день.
6

Недельный итог

Удобно отправлять по понедельникам: видно неделю целиком, лидеров и слабые места.

Каждый понедельник подготовь недельную сводку по продажам ОСАГО и отправь результат в Telegram чат @тутчат. Используй прошлую полную неделю с понедельника по воскресенье и сравни ее с неделей до этого. Стоимость выпуска и курс могут измениться — перед оплатой смотрите актуальные значения в приложении.

Файл настроек

{ "env": { "ANTHROPIC_API_KEY": "ВАШ КЛЮЧ ИЗ OmniRoute", "ANTHROPIC_BASE_URL": "ВАША ССЫЛКА ИЗ OmniRoute, ПО УМОЛЧАНИЮ http://localhost:20128/v1", "API_TIMEOUT_MS": "3000000", "ANTHROPIC_DEFAULT_HAIKU_MODEL": "kr/claude-haiku-4.5", "ANTHROPIC_DEFAULT_SONNET_MODEL": "kr/claude-sonnet-4.5", "ANTHROPIC_DEFAULT_OPUS_MODEL": "qw/qwen3-coder-plus" } }

В полях ANTHROPIC_DEFAULT_HAIKU_MODEL, ANTHROPIC_DEFAULT_SONNET_MODEL и ANTHROPIC_DEFAULT_OPUS_MODEL вы сами задаёте модели, которые вам нужны.

1. Yes

Личный сервер

Купить сервер

Покупаем недорогой сервер, выбираем страну и ставим чистую Ubuntu 24.04.

Шаги 1–7
1

Открыть раздел виртуальных серверов

Перейдите в панель управления сервером. В меню откройте Товары/Услуги → Виртуальные серверы.

2

Заказать новый сервер

Нажмите Заказать. Откроется форма, где выбирают страну, срок оплаты и размер сервера.

3

Выбрать страну сервера

Для защищённого подключения лучше выбирать страну ближе к вам и к нужным сервисам. Чем ближе дата-центр, тем ниже задержка.

Ближайшая ЕвропаФинляндия, Эстония, Латвия, Литва, Польша: примерно 35–70 мс.
Западная и Северная ЕвропаНидерланды, Норвегия, Чехия, Австрия, Дания, Италия, Бельгия, Швейцария, Швеция, Франция: примерно 45–90 мс.
Северная АмерикаКанада и США: примерно 120–190 мс. Брать только если нужен именно американский или канадский IP.

Если не знаете, что выбрать, начните с ближайшей Европы: обычно она даёт нормальную скорость и меньше задержек.

4

Выбрать период оплаты

Для проверки достаточно оплаты на месяц. На скрине пример цены: 360 RUB/месяц, при оплате на 3 месяца, полгода или год обычно применяется скидка.

5

Поставить Ubuntu 24.04

В поле Операционная система выберите Другое → Ubuntu 24.04. Предустановленное ПО оставьте не установлен.

6

Оставить минимальные ресурсы

Для личного туннеля обычно хватает самого маленького тарифа: 25 ГБ диск, 2 ГБ RAM, 1 CPU и 1 публичный IPv4. IPv6 можно оставить, если он бесплатный.

7

Оплатить и дождаться доступа

После оплаты дождитесь создания сервера. В карточке услуги появятся IP-адрес, логин root и пароль или данные для SSH (безопасный вход на сервер).

Настроить AmneziaVPN

AmneziaVPN сама подключится к серверу по SSH (безопасный вход на сервер), установит нужные файлы и настроит защищённое подключение.

Шаги 1–5
1

Открыть своё подключение

Запустите AmneziaVPN и выберите плитку Self-hosted для настройки на своём сервере.

2

Ввести данные сервера

Укажите IP-адрес сервера, имя пользователя root и пароль от сервера. Если SSH (вход на сервер) работает на нестандартном порту, укажите IP в формате IP:порт.

3

Нажать «Продолжить»

AmneziaVPN проверит доступ к серверу и начнёт настройку. Обычно дальше нужно просто подождать: приложение само всё установит.

4

Выбрать протокол

Если приложение спросит протокол, начните с AmneziaWG или WireGuard. Они быстрые и обычно подходят для личного подключения.

5

Подключиться и проверить работу

После завершения установки нажмите подключение в AmneziaVPN, затем проверьте IP через сервис проверки IP или любой похожий сервис.

Протокол

Протокол — это способ, которым защищённое подключение передаёт трафик. От него зависят скорость и стабильность.

Список
AmneziaWGЛучший стартовый вариант: быстрый и обычно хорошо работает в сложных сетях.
WireGuardОчень быстрый и простой. Хорош для сетей, где стандартное подключение работает стабильно.
XRay VLESS RealityПодходит, если стандартное подключение работает нестабильно.
OpenVPNСтарый надёжный вариант. Работает почти везде, но часто медленнее.
OpenVPN over CloakOpenVPN с дополнительным транспортным слоем. Полезен в сетях с жёсткими правилами фильтрации.
OpenVPN over ShadowsocksЕщё один вариант, если стандартное подключение работает нестабильно.
IKEv2/IPsecСтабильный вариант для телефонов, но не всегда удобен на роутерах.

Если не получается подключиться

Что проверить, если сервер не создаётся, SSH не работает или подключение не поднимается.

Проверка
1

Проверить IP, логин и пароль

Убедитесь, что IP сервера скопирован без пробелов, логин указан root, а пароль взят именно от созданного сервера.

2

Дождаться установки Ubuntu

Сразу после оплаты сервер может ещё устанавливаться. Подождите несколько минут и повторите подключение в AmneziaVPN.

3

Проверить вход на сервер

Если приложение не подключается, попробуйте зайти на сервер через терминал командой ssh root@IP_СЕРВЕРА. Если SSH (вход на сервер) не пускает, проблема в доступах или сервере, а не в приложении.

4

Сменить протокол

Если подключение создаётся, но сайты открываются плохо, попробуйте другой протокол. Начните с AmneziaWG или WireGuard.

5

Выбрать ближний дата-центр

Если пинг высокий, создайте сервер ближе к вашему региону. Обычно быстрее работают Финляндия, Эстония, Латвия, Литва или Польша.

Роутер и туннель

Подключить туннель

Роутер управляет защищённым подключением сам. Телефон, ноутбук и другие устройства используют его без отдельного приложения.

Keenetic / OpenWrt
1

Сохранить файл настроек AmneziaWG

В AmneziaVPN откройте сервер, выберите экспорт AmneziaWG и сохраните файл .conf (файл настроек подключения).

2

Обновить систему

На Keenetic обновите KeeneticOS. Если AmneziaWG не импортируется, включите канал разработчика. Для OpenWrt нужна версия 24.10.3+.

3

Поставить WireGuard

В Keenetic откройте Управление → Настройки системы → Изменить набор компонентов и включите WireGuard.

4

Загрузить файл настроек

Перейдите в Интернет → Другие подключения, нажмите Загрузить из файла и выберите свой .conf (файл настроек подключения). Пока не делайте его основным выходом в интернет.

5

Добавить DNS-профили

В Интернет-фильтры → Настройка DNS добавьте защищённый Google DNS (служба адресов сайтов): DoT с 8.8.8.8 и dns.google, а также DoH с https://dns.google/dns-query. DoT и DoH — это защищённые варианты DNS.

6

Отключить DNS провайдера

В разделе Интернет → Кабель Ethernet включите Игнорировать DNSv4 и Игнорировать DNSv6 интернет-провайдера. Так роутер не будет брать DNS (адреса сайтов) у провайдера.

7

Вариант 1: весь трафик устройства через VPN

Это самый простой вариант: выбранный компьютер, телефон или телевизор будет открывать все сайты через AmneziaWG. Откройте Интернет → Приоритеты подключений, создайте отдельную политику, например Только ВПН, и оставьте в ней только подключение AmneziaWG. Обычное Ethernet-подключение в этой политике отключите, чтобы устройство не уходило напрямую мимо VPN.

После создания политики перейдите на вкладку Применение политик и назначьте её нужному устройству, например вашему компьютеру. В примере устройство помещено в политику Только ВПН, поэтому весь его трафик пойдёт через туннель.

8

Вариант 2: маршрутизация только нужных сайтов

Этот вариант нужен, если через VPN должны идти только отдельные сайты и сервисы, а остальной интернет должен работать напрямую. Сначала откройте Сетевые правила → Маршрутизация → Списки доменных имен и создайте список доменов, например Маршруты часть 1. Вставьте домены по одному в строке. Все поддомены указанных имён будут учитываться автоматически.

Для ChatGPT, OpenAI и других сервисов добавьте домены ниже. Если список получается большим, разделите его на несколько частей: Маршруты часть 1, Маршруты часть 2 и так далее.

openai.com api.openai.com chatgpt.com cdn.oaistatic.com oaistatic.com oaiusercontent.com

После списка доменов откройте Сетевые правила → Маршрутизация → Маршруты DNS и создайте правило маршрутизации. Выберите нужный список доменных имён, в поле Адрес шлюза укажите адрес из файла .conf, а в поле Интерфейс выберите подключение AmneziaWG. Оставьте включёнными Добавлять автоматически и Эксклюзивный маршрут, чтобы совпавшие домены ходили только через выбранный туннель.

После сохранения проверьте, что правило привязано к AmneziaWG, а обычные сайты без правила продолжают открываться через провайдера.

Готовые списки доменов для маршрутизации можно скачать здесь и перенести в правила роутера:

  • Google и YouTube
  • Игры
  • AI, рабочие сервисы и Adobe
9

Включить и проверить туннель

Вернитесь в Другие подключения, включите AmneziaWG и проверьте, что появился handshake (роутер и сервер увидели друг друга) и пошёл трафик. Если меняли настройки через CLI (командную строку роутера), сохраните их командой system configuration save.

10

Если роутер на OpenWrt

Подключитесь по SSH (безопасный вход на роутер), проверьте интернет командой ping github.com, установите AmneziaWG и загрузите .conf в LuCI (веб-панель OpenWrt) как подключение AmneziaWG.

sh <(wget -O - https://raw.githubusercontent.com/Slava-Shchipunov/awg-openwrt/refs/heads/master/amneziawg-install.sh)
